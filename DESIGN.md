# AppDirect - Style Reference
> Make the app feel like it was built by AppDirect — match the brand of https://appdirect.com.

Brand signals inferred from https://appdirect.com (AppDirect).
Company positioning: "AppDirect powers millions of cloud subscriptions worldwide with marketplace, billing, reseller, and distribution solutions."
Reference brand imagery: https://dcnxfkgt2gjxz.cloudfront.net/_1200x630_crop_center-center_82_none/AppDirect-Subscription-Commerce-Solution.jpg?mtime=1610674184 (use it to judge the brand's look, not necessarily as an asset).

## Do

- Treat https://appdirect.com as the visual reference: match its palette, tone, and level of polish.
- Use the brand primary color for primary actions and key accents.
- Use the company logo (https://appdirect.com/shortcut-icon.ico) in the app header / brand surfaces.

## Don't

- Don't invent a clashing palette — derive secondary tones from the brand colors above.
- Don't render the company name in a generic template way; this is their branded tool.

## Agent Prompt Guide

- Read this file before creating or modifying UI.
- Use these colors, typography, spacing, surfaces, and component treatments as the visual source of truth.
- Adapt the style to the user's app concept; do not copy unrelated brand names or product-specific content.
- Preserve accessibility and contrast when applying the style.
